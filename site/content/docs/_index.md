GameKit gives a Go game what it needs from the platform:

- **gpu** — a thin, bindless, GPU-driven interface over Vulkan and Metal.
- **ui** — native windows and controls: Cocoa on macOS, Win32 on Windows, GTK 4
  on Linux.
- **keyboard** and **pointer** — portable keys, buttons and modifiers.

For every type and function, see the
[API reference](https://pkg.go.dev/github.com/bluescreen10/gamekit).
